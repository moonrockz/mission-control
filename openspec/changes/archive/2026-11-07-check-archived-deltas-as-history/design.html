Context

See proposal.md. pkgs/okf/openspec/checks.mbt runs check_modified_unknown and check_unknown_capability on every spec delta. check_not_ears in ears.mbt already skips a document whose state is archived.

Decisions

CHK-1. Skip archived deltas in the two archive-time rules

A helper in_archived_change(doc) reads the state metadata, as the EARS rule does, and both rules skip such a delta. Alternative: skip only REMOVED requirements of archived changes. Rejected: a MODIFIED requirement of an old archived change fails the same way after a later rename or removal; OpenSpec itself runs these checks only at archive time.

Risks and trade-offs

RiskMitigation
A wrong delta in an archived change is no longer reported.OpenSpec refuses such a delta when it archives, and the rules still check every active change.
